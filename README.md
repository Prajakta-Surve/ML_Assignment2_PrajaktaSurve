# Heart Disease Prediction — Machine Learning Assignment 2

## a. Problem Statement

Cardiovascular disease is one of the leading causes of death worldwide. Early
identification of individuals at risk enables timely intervention. This project
frames heart disease risk prediction as a **binary classification problem**:
given a set of health, lifestyle, and demographic indicators for an individual,
predict whether they have (or have had) heart disease / a heart attack
(`1`) or not (`0`).

Five classical ML models are implemented, evaluated, and compared on the same
dataset, and the best-performing model(s) are exposed through an interactive
Streamlit web application.

## b. Dataset Description

- **Name:** Heart Disease Health Indicators Dataset (BRFSS 2015)
- **Source:** Kaggle —
  https://www.kaggle.com/datasets/alexteboul/heart-disease-health-indicators-dataset
  (originally derived from the CDC's Behavioral Risk Factor Surveillance
  System survey)
- **File used:** `heart_disease_health_indicators_BRFSS2015.csv`
- **Instances:** 253,680 (a stratified sample of this is used for training —
  see `model/train_models.py --sample_frac`; still far exceeds the minimum of
  500)
- **Features:** 21 (exceeds the minimum of 12), including `HighBP`,
  `HighChol`, `CholCheck`, `BMI`, `Smoker`, `Stroke`, `Diabetes`,
  `PhysActivity`, `Fruits`, `Veggies`, `HvyAlcoholConsump`, `AnyHealthcare`,
  `NoDocbcCost`, `GenHlth`, `MentHlth`, `PhysHlth`, `DiffWalk`, `Sex`, `Age`,
  `Education`, `Income`
- **Target column:** `HeartDiseaseorAttack` (`0` = No heart disease/attack,
  `1` = Has had heart disease/attack)
- **Task type:** Binary classification

## How to Run Locally

1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt

2. Download the dataset from Kaggle and place it at
   `data/heart_disease_health_indicators_BRFSS2015.csv`.
3. Train the models:
   ```bash
   cd model
   python train_models.py --data ../data/heart_disease_health_indicators_BRFSS2015.csv
   cd ..
   ```
   This creates the `.pkl` model files, `model/metrics_comparison.csv`, and
   `test_data.csv` at the project root.
4. Launch the app:
   ```bash
   streamlit run app.py
   ```

## Deploying on Streamlit Community Cloud

1. Push this entire folder to a public GitHub repository (include the
   generated `.pkl` files and `test_data.csv` — do **not** commit the full
   raw dataset if it's very large).
2. Go to https://streamlit.io/cloud and sign in with GitHub.
3. Click **New App**, select your repository and branch (`main`), and set
   the main file path to `app.py`.
4. Click **Deploy**.
5. Once live, use the sidebar to upload `test_data.csv` (or rely on the
   bundled copy), pick a model from the dropdown, and view metrics, the
   confusion matrix, and the classification report.
